# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

By participating, you agree to uphold its terms. Please read the
linked document in full before contributing.

## Reporting

Concerns about community conduct can be reported to the maintainers
via a GitHub issue marked `conduct`, or directly via the email listed
on the maintainer's GitHub profile.

For security-related reports, please open a private [security
advisory](https://github.com/hadamrd/titan/security/advisories/new) instead.
